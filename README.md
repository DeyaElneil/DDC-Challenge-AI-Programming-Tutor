# DDC-Challenge-AI-Programming-Tutor
The AI Programming Tutor is an AI Model specialized in helping and teaching students programming concepts in a way that’s easy to digest and comprehend, rather than giving the codes and expecting it to be implemented, the AI Model will explain concepts and provide multiple examples and analogies while teaching.
